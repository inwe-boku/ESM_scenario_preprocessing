## Output table (sheet `data`)
Columns: scenario | sector | carrier | unit | year | value. Every combination is present, with 0
where a sector doesn't use a carrier. No subtotals or totals: summing the carriers of a sector
gives AIT's "Total energy".

Sectors: IronSteel, Chemical, PulpPaper, NonMetalicMinerals, Machinery, NonFerrousMetals,
TransportEquipment, FoodAndBeverages, Wood, Textiles, NonSpecifiedIndustry, Construction, Mining.

Carriers and their source labels:
Waste; Biofuels; Electricity; ElectricityHP (El. for Heat Pumps / Electricity for HPs);
SolarThermal; Coal; Oil; DistrictHeating; GasGridMix; Hydrogen.

## Rules
1. GasGridMix covers methane-type gases only: natural gas (first "Gas grid mix" or "CH4" row
   inside AIT's table) + Bio-CH4/Biogas + Synth-CH4. It never contains hydrogen. Build it from
   these component rows. Never copy the gas aggregate rows below the totals ("Gas grid mix",
   "Gas grid ix", "Natural gas, Bio-CH4 and Syn-CH4"): outside IronSteel and Chemical they
   include hydrogen. Use them only as a check.
2. Hydrogen = the "Hydrogen" row inside AIT's table (directly after District Heating), in every
   sector. It is total hydrogen demand: no distinction between hydrogen from the pipeline and
   hydrogen made on site.
3. Drop "El. for H2" and "Transformation losses H2" (IronSteel, Chemical). The hydrogen is
   already counted under Hydrogen, so adding the electricity would double count. In the source,
   El. for H2 = Hydrogen / 0.7 and El. for H2 = Hydrogen + losses.
4. Drop the extra hydrogen rows. In Sc1 these are the "H2" rows below each total and the top
   "Hydrogen" row in Chemical (row 43; its label is in column B). In Sc2a they are the
   "Hydrogen" rows at the top of each block. They equal the gas aggregate × an assumed H2 share
   of the gas grid, identical in every sector:
   - Sc1: 10.9 % / 17.6 % / 32.3 % / 74.2 % / 100 % / 100 % (2025–2050)
   - Sc2a: 0 / 0 / 27.7 % / 93.4 % / 86.5 % / 75.5 %
   They are not part of AIT's totals.
5. Drop every "Total energy" row, the gas aggregate rows, and the second, identical "Hydrogen"
   row below the IronSteel total.
6. In Sc1 Construction, the row labelled "Gas grid mix" below the total actually contains the H2
   share values. Ignore it; GasGridMix is built from components.
